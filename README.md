# Таблица пользователей — SQL-скрипты

## 📋 Описание задачи

Написать три SQL-скрипта для работы с таблицей `PERSONS`:
1. Создание таблицы с составным первичным ключом.
2. Поиск имени и фамилии пользователей из Москвы.
3. Поиск всех полей пользователей старше 27 лет с сортировкой по убыванию возраста.

## 🎯 Цель

Отработать:
- Написание DDL-скриптов (`CREATE TABLE`);
- Написание DML-запросов (`SELECT`);
- Работу с составным первичным ключом (`PRIMARY KEY`);
- Фильтрацию (`WHERE`) и сортировку (`ORDER BY`).

## 🛠️ Используемые технологии

- SQL (стандарт ANSI SQL)
